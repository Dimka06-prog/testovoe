### Результат
Файл `daily_by_sku.csv` появится в корневой директории проекта. Он содержит агрегированные данные по артикулам и датам с колонками:

- `order_date` - дата заказа
- `orders` - количество заказов (включая отменённые)
- `revenue` - выручка (только по доставленным заказам)

## Какие проблемы нашёл в данных и как с ними поступил

1. **Дубликаты строк** (60 дубликатов)
   - Решение: удалены с помощью `drop_duplicates()`, оставлено первое вхождение
   - Обоснование: по условию один заказ должен учитываться один раз, даже если строка встречается дважды

2. **Пропуски в quantity** (4 строки)
   - Решение: удалены строки с отсутствующим значением quantity
   - Обоснование: невозможно рассчитать выручку без количества

3. **Опечатки в статусах** (разные регистры: delivered, Delivered, DELIVERED, cancelled, Cancelled, CANCELLED, canceled)
   - Решение: приведены к нижнему регистру с помощью `str.lower()`
   - Обоснование: необходимо корректно идентифицировать delivered для расчёта выручки
